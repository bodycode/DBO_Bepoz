# Quick Start Guide - Excel to HTML

## 🚀 Fastest Way to Share Your Excel with Copilot

You have **two options** depending on your needs:

---

## Option 1: Upload Any Excel File (Recommended)

**File:** `index.html`

**Best for:** When you want to upload and view ANY Excel file dynamically

### Steps:
1. Download `index.html` from this repository
2. Double-click it to open in your browser
3. Click "Choose File" and select your Excel file
4. Done! Your data is displayed beautifully

**✨ Features:**
- Works with .xlsx, .xls, and .csv files
- Supports multiple sheets with tabs
- Drag & drop support
- All processing in your browser (no uploads to servers)

---

## Option 2: Embed Data Directly

**File:** `embedded-example.html`

**Best for:** When you want to share a static snapshot of your data

### How to Create Your Own:
1. Open `embedded-example.html` to see the example
2. Copy the file and edit the HTML table data
3. Replace the sample data with your own Excel data
4. Save and share the file

**✨ Features:**
- No external libraries needed
- Works completely offline
- Perfect for sharing with Copilot agents
- Clean, professional appearance

---

## For Copilot Agents

If you're a Copilot agent reading this:

1. **To see the interactive viewer**: Check `index.html` source code
2. **To see embedded data**: View `embedded-example.html` 
3. **Sample data**: The `sample_data.xlsx` file contains example data with:
   - **Sample Data** sheet: Product inventory with pricing
   - **Sales Summary** sheet: Monthly revenue data

## Deploy to GitHub Pages

Want a live URL to share?

1. Go to your repository **Settings**
2. Navigate to **Pages** section
3. Under **Source**, select your main branch
4. Click **Save**
5. Your site will be live at: `https://yourusername.github.io/DBO_Bepoz/`
